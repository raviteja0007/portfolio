## 🌌 Key Features

- **Hero Terminal Boot Sequence**: Typewriter initialization sequence (`> initializing_ravi_teja.exe`).
- **Personnel Dossier**: ID card panel with biometric HUD stats, animated scan lines, custom cybernetic avatar portrait (`RX-01`), and core focus pills.
- **The Arsenal (Skills Matrix)**: Category-filterable skill clusters with animated percentage meters (*AI/ML, Cloud Security, Full Stack, Core CS, Tools & Infra*).
- **Mission Logs (Projects)**: Interactive case-file cards for:
  - **Career Stimulator**: High-performance REST API backend with token authentication, input validation, and SQLite integration.
  - **Green Elixir Vision (Ayurveda Chatbot)**: NLP recommendation engine (Python, Flask, React, PostgreSQL) mapping symptoms to remedies with a botanical plant knowledge base.
- **Field Deployments (Experience)**: Timeline log highlighting Qspiders (*Java Full Stack Intern*) & EZTS (*Python/ML Training*).
- **Clearance Badges**: Holographic security badges for Microsoft Azure AZ-900, Linux RH124-134, Python, GCP Gen-AI, and Deep Learning Specialization.
- **Interactive CLI Terminal**: Functional command prompt (`raviteja@command-center:~$`) accepting custom commands (`help`, `whoami`, `skills`, `projects`, `clearances`, `contact`, `matrix`, `clear`).
- **Open Channel**: Quick contact links with 1-click copy toast triggers and an interactive message form.
- **Web Audio SFX**: Synthesized retro-futuristic sound effects with a status bar audio toggle (`[ SFX: ON/OFF ]`).
